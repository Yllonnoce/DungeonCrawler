# Enemy grunts

CC0 (https://creativecommons.org/publicdomain/zero/1.0/); fetched by `scripts/fetch_grunts.py`. AudioManager plays each folder as
`grunt_hurt_<set>` / `grunt_death_<set>`, pitched by `VoiceSets.PitchOffset` (small +0.25, medium 0,
large -0.25, boss -0.4), so small and medium share clips.

- p1: "80 CC0 creature SFX" by rubberduck, https://opengameart.org/content/80-cc0-creature-sfx (80-CC0-creature-SFX_0.zip)
- p2: "80 CC0 creture SFX #2" by rubberduck, https://opengameart.org/content/80-cc0-creture-sfx-2 (80-CC0-creature-sfx-2.zip)
